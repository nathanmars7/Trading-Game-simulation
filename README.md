# Trading game simulation

> **Archived learning exercise (2022).** Kept as-is; not maintained and not part of the current portfolio.

A first Python script, written while learning git and VS Code. It simulates a betting game: a bag holds six green and four red marbles, each round draws one, and a purse of 1000 goes up or down with the result over a number of rounds.

## Run it

```bash
python3 main.py
```
